# Auren 2.9

Se usa el icono elegido de la rama `feat/todo-junto`: monograma A con órbita y satélite en bronce sobre grafito. El vector Android mantiene viewport 108 × 108 y el símbolo dentro de su zona segura central. La versión temática usa el mismo dibujo monocromo.

`auren-master.png` y `assets/auren-mark.png` se rasterizan del vector seleccionado para que el chat muestre la misma identidad. `drawable-nodpi/auren_notification.png` contiene su silueta blanca centrada. La aplicación mantiene el package ID y la firma de actualización.
